# 🎂 Happy Birthday Afeeq

A very serious, very professional birthday website.

## Deploy to GitHub Pages
1. Create a new repo on GitHub (e.g. `happy-birthday-afeeq`).
2. Upload everything in this folder (`index.html`, `style.css`, `script.js`, `img/`) to the repo root.
3. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. After ~1 minute it's live at `https://<your-username>.github.io/happy-birthday-afeeq/`.
